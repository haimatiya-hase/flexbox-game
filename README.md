# FlexLab — Flexbox Learning Game

FlexLab is an interactive game created for Assignment 2 in the Web Application Development course. It helps users learn and practice CSS Flexbox by solving layout challenges.

## Live Demo

[Play FlexLab](https://haimatiya-hase.github.io/flexbox-game/)

## How to Play

1. Read the mission briefing and the target Flexbox values.
2. Choose the matching values in the control panel.
3. Press **Check solution**.
4. A correct solution unlocks the next stage.
5. Completed stages can be revisited with the Previous and Next buttons.
6. Complete all six stages to see the mission-complete celebration.

## Features

- Six progressive Flexbox stages.
- Interactive controls for `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, and `align-content`.
- Correct and incorrect solution feedback.
- Locked progression with navigation between unlocked stages.
- Reset, score, attempt counter, and progress indicator.
- Responsive interface with a fixed-size game board.
- Final celebration screen after completing all stages.

## Technologies

- HTML5
- CSS3 Flexbox
- Vanilla JavaScript

The project uses no external JavaScript libraries and does not use CSS Grid.

## Run Locally

Open `index.html` in a web browser.

## Project Files

- `index.html` — game structure and controls.
- `style.css` — visual design, responsive layout, and animations.
- `script.js` — stages, game logic, navigation, validation, and scoring.
